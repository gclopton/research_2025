# Code completion playground

Sixteen synthetic questions cover keywords, expressions, partial lines, multiline blocks, and language-specific concepts. Expand a language group to try four questions. Responses are matched against listed alternatives, not executed. Exact matching preserves indentation and case; LF and CRLF are equivalent. Tab moves between blanks; Enter adds a line inside a blank.

Use Edit question to inspect or change alternatives. In the Code source field, select code and press Ctrl+Shift+B to create a blank. Every alternative has a separate multiline field.
