# Courses and history

Use **Study Studio: Manage courses** to create a course or rename its title. Course IDs remain stable when titles change.

Open a question or exam source note, then run **Study Studio: Assign current note to courses**. You can select multiple courses, or none for unassigned material. Reopen any already-open question editor or practice card after changing its memberships.

A practice card has **Course for this attempt**. Choose its course before answering; Unassigned is the default. An exam with course memberships asks which course to use when you start it. The selected course is saved with that attempt/session. Changing memberships or renaming a course later does not rewrite historical records.

**Study Studio: Show review history** now combines practice and submitted exam questions in a workspace tab. Filter by course, first scored attempt, retry, or unscored reveal. First/retry is calculated per question and course using the available history. Different variants retain separate identities. Old records remain Unassigned, and unfinished exams are not scored here. Open original record lets you inspect the saved source.

Try [[Course foundation playground]] using its linked synthetic question. Analytics charts, active timing, review scheduling and the calendar are later milestones.
