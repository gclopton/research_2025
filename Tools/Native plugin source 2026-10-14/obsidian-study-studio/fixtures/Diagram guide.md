# Diagram labeling

Choose **Label the diagram** when creating a Study Studio question. In the editor, choose a vault image or import one. Imported images follow the vault attachment location; importing leaves the file available even if you cancel the question.

Add a cover to hide a printed label without altering the original image. Set its opaque color to match the image background. Place an answer label over the cover or beside the feature being tested. Drag rectangles or focus them and use arrow keys; Shift moves farther. Percent fields control exact positions and sizes. Optional leader lines connect a label to an image location. Move labels earlier to change keyboard order.

Each label has accepted answers, one alternative per line, with Math Studio available for editing equations. Mark mathematical labels as **Math answer** so revealed expressions render correctly, and enable case sensitivity where capitalization matters. Mathematical equivalence is not inferred: supply the accepted forms explicitly.

In a question, type into a label or use its Math button / Ctrl+M. Shift+Enter returns from Math Studio with rendered mathematics. Check answer fills the correct solutions and marks correct/incorrect responses; reveal fills solutions without scoring. Original responses remain in local history. Diagram questions can be placed in note groups and exams like other question types.

The image and its overlays scale together. Narrow note panes scroll horizontally to keep the inputs readable. Keep image filenames stable: custom YAML image paths do not yet follow file renames, and history snapshots preserve the question layout but reference the image file rather than copying its pixels.

The lab's **Diagram labeling playground** contains the fluid displacement example and a synthetic cover-and-label example. **Diagram sampler** tests labels in an exam. The lab also has **Skull anatomy practice**, with 22 bone labels across lateral and frontal views.

For crowded images, increase **Minimum readable image width** in the editor. Text-only diagram fields omit the Math button so Tab moves directly to the next label; Ctrl+M remains available.
