# Grouped review

Open a review group to work through its questions together. The Expand all / Collapse all commands apply to this note. Finished Math Studio edits and typed answers save locally; wait for **Draft saved locally** before restarting. Use **Try again** after a completed question to start a fresh attempt.

```study-group
title: Quick foundations
questions:
  - demo-matrix
  - demo-gradient
```

```study-group
title: Calculus practice
questions:
  - demo-integral-table-mixed
  - demo-table
```

Use **Study Studio: Insert question group** from the command palette to add a group to another note. The Expand all and Collapse all commands can be assigned hotkeys in Obsidian settings. Expanding never reveals solutions.
