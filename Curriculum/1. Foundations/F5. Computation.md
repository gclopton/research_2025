# F5. Computation

### F5.1 Programming for Scientists and Engineers — Assess

**Why it's here:** The working language of everything in research area 04 and 07.

**Required content:**

- Python with NumPy/SciPy/matplotlib; scripting and data analysis.
- Program design: functions, modules, testing habits.
- File formats and data handling for simulation output.
- Reading literacy in a compiled language (C/C++/Fortran) — enough to read VASP/LAMMPS/EPW internals, not to write them.

### F5.2 Data Structures and Algorithms — Assess

**Why it's here:** Algorithmic literacy: complexity, data layout, and the structures scientific codes are built from.

**Required content:**

- Arrays, lists, hash tables, trees, graphs.
- Sorting and searching; complexity analysis (big-O).
- Recursion; dynamic programming at first exposure.
- Memory layout and cache-friendliness at a conceptual level.

### F5.3 Numerical Methods — Assess

**Why it's here:** The single introductory numerical course of the foundations tier (dedupes the draft's separate "Numerical Analysis" and the math-area "Numerical Methods"). Research 4.1–4.5 are the graduate treatments.

**Required content:**

- Floating-point arithmetic and error.
- Root finding; interpolation; quadrature.
- Basic linear-system solving; least squares.
- Basic ODE integrators (Euler, Runge–Kutta) and stability at first exposure.

### F5.4 Computational Physics — Assess

**Why it's here:** The project-based integrator: physics problems solved end-to-end in code — the habit layer under all of research area 04.

**Required content:**

- Simulation projects: oscillators, orbits, random walks, Ising model, simple MD.
- Monte Carlo at an introductory level.
- Discretizing simple PDEs (diffusion equation).
- Verification against analytic solutions; convergence checks.

### F5.5 Unix, Shell, and Research Computing Craft — Optional

**Why it's here:** Review-tier for a working cluster user: the tooling layer under daily practice. Research 4.14 adds the rigor (provenance, workflows, regression testing).

**Required content:**

- Shell fluency; job schedulers; remote workflows.
- Version control with git.
- Environments and dependency management.
- Plotting/analysis pipelines that are reproducible by default.
